# 🌍 Wanderlust - Your Gateway to Extraordinary Stays

> Discover. Explore. Experience.

Wanderlust is a full-stack travel marketplace inspired by Airbnb, designed to help travelers discover unique accommodations while allowing hosts to showcase and manage their properties effortlessly.

Built with modern web technologies, the platform focuses on seamless user experience, secure authentication, interactive location discovery, and real-world deployment practices.

link:- https://wanderscape-nkz7.onrender.com/listings

---

## ✨ Why Wanderlust?

Planning a trip should be exciting, not complicated.

Wanderlust bridges the gap between travelers and hosts by providing an intuitive platform where users can explore beautiful destinations, share experiences through reviews, and discover properties with interactive maps and smart search capabilities.

Whether you're searching for a cozy mountain cabin, a luxury villa, or a lakeside campsite, Wanderlust helps you find your next unforgettable stay.

## 🚀 Features

### 🔐 Secure User Authentication

* User registration and login functionality
* Session-based authentication
* Secure session storage using MongoDB
* Authorization controls for listings and reviews

### 🏡 Property Management

* Create new travel listings
* Upload high-quality property images
* Edit existing listings
* Delete listings with authorization checks
* View detailed property information

### ⭐ Reviews & Ratings

* Leave ratings and written reviews
* Interactive star-based rating system
* Delete personal reviews
* Community-driven property feedback

### 🗺️ Interactive Maps & Geolocation

* Automatic address geocoding using Mapbox
* Interactive maps for every listing
* Better destination visualization for travelers

### 🔍 Smart Search Experience

Search listings by:

* Destination Name
* Location
* Country
* Property Category

Get instant results without unnecessary navigation.
